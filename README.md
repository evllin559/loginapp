# Ingles Facil

Sistema web simples para ensinar ingles a iniciantes de forma pratica e facil.

## O que inclui

- Licoes guiadas por situacoes do dia a dia.
- Frases em ingles com traducao para portugues.
- Botao de pronuncia usando o recurso de voz do navegador.
- Flashcards interativos para memorizar vocabulario.
- Quiz rapido para praticar frases essenciais.
- Plano diario de estudo em 15 minutos.

## Como usar

Abra o arquivo `index.html` em um navegador moderno.

Tambem e possivel servir a pasta localmente:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000`.
